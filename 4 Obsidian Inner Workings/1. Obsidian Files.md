
# Obsidian - configuration as JSON

## Registration 

Obsidian keeps its settings in plain JSON files, at **two levels**:

| Level | Where | What it answers |
| --- | --- | --- |
| Global (the app) | `obsidian.json` in the app's config folder | *Which vaults do I know about, and where are they?* |
| Local (one vault) | `.obsidian/` inside the vault folder | *How should this vault look and behave?* |

A **vault** is just a normal folder. "Registering" a vault means Obsidian writes that folder's path into the global `obsidian.json`. Nothing is copied or moved.

### 1. Global: `obsidian.json` (the vault registry)

Location by OS:

- macOS: `~/Library/Application Support/obsidian/obsidian.json`
- Windows: `%APPDATA%\obsidian\obsidian.json`
- Linux: `~/.config/obsidian/obsidian.json`

Example with two registered vaults:

```json
{
  "vaults": {
    "a1b2c3d4e5f60718": {
      "path": "/Users/student/github/obsidian_tutorial",
      "ts": 1764002922000,
      "open": true
    },
    "9f8e7d6c5b4a3921": {
      "path": "/Users/student/Documents/Class Notes",
      "ts": 1763900000000
    }
  }
}
```

- The key (`a1b2c3d4e5f60718`) is the **vault id**, a random 16-character hex string Obsidian creates once.
- `path` is the folder on disk. This is the actual link between Obsidian and your files.
- `ts` is a timestamp in milliseconds (when the vault was last opened).
- `open: true` means the vault was open when Obsidian last quit, so it reopens it on start.

In the same folder there is also one small file per vault, named after its id (for example `a1b2c3d4e5f60718.json`). It remembers that vault's **window** size and position. The id is the glue: `obsidian.json` maps *id → folder*, and `<id>.json` stores *id → window state*.

### 2. Local: the `.obsidian/` folder (per-vault settings)

Every vault carries its own settings inside it. This tutorial vault looks like this:

```
obsidian_tutorial/            <- the vault (path stored in obsidian.json)
├── .obsidian/                <- settings for THIS vault only
│   ├── app.json              <- editor and file options
│   ├── appearance.json       <- theme, ribbon, CSS snippets
│   ├── core-plugins.json     <- which core plugins are on or off
│   ├── graph.json            <- graph view settings
│   ├── workspace.json        <- open tabs, panes, recent files
│   └── snippets/             <- .css files used by appearance.json
├── 1. Obsidian Files.md
└── README.md
```

Real examples from this vault:

`app.json` (Settings → Editor / Files and links):

```json
{
  "livePreview": false,
  "attachmentFolderPath": "./pic"
}
```

`appearance.json` (Settings → Appearance):

```json
{
  "showRibbon": true,
  "enabledCssSnippets": ["tutorial-headings", "hide-link-tabs"]
}
```

`core-plugins.json` (Settings → Core plugins):

```json
{
  "graph": true,
  "backlink": true,
  "daily-notes": true,
  "footnotes": false
}
```

`workspace.json` is written automatically as you work. For example, it records that `1. Obsidian Files.md` is open in a tab. You rarely edit it by hand. See [[2 app.json and workspace.json]] for more detail.

### 3. How the two levels connect

```
obsidian.json                              the vault folder
-------------                              ----------------
"a1b2c3d4e5f60718": {
   "path": "/Users/.../obsidian_tutorial" ──► obsidian_tutorial/
}                                              └── .obsidian/
a1b2c3d4e5f60718.json  (window size)               ├── app.json
                                                   ├── appearance.json
                                                   └── ...
```

1. You start Obsidian.
2. It reads `obsidian.json` to find the vault marked `open` (or shows the vault switcher).
3. It follows `path` to the folder.
4. It reads that folder's `.obsidian/*.json` to load the theme, plugins, and tabs.

### 4. What this means in practice

- **Settings travel with the folder.** Because `.obsidian/` lives inside the vault, cloning this repo with `git clone` gives you the same theme, snippets, and plugins. Only the registration is new.
- **Opening a folder = registering it.** "Open folder as vault" adds a new id + path to `obsidian.json`. If the folder has no `.obsidian/`, Obsidian creates one with default settings.
- **"Remove from list" only edits `obsidian.json`.** The vault switcher entry disappears, but your notes and `.obsidian/` stay on disk.
- **Moving or renaming the folder** outside Obsidian breaks the `path`. Obsidian can no longer find it; open the folder again to register the new path.
- **Two vaults never share settings**, because each has its own `.obsidian/`.

### Try it

1. Quit Obsidian. Open `obsidian.json` and find the id whose `path` is this tutorial folder.
2. Open `.obsidian/appearance.json` and change `"showRibbon": true` to `false`. Start Obsidian: the left ribbon is gone. Change it back.
3. Turn a core plugin on or off in Settings, then look at `core-plugins.json` to see the value flip.
