이미지나 첨부파일이 자동으로 `pic` 폴더에 저장되게 하려면 **Settings → Files and links → Default location for new attachments**에서 **"In the folder specified below"**를 고르고 경로에 `pic`을 넣으시면 됩니다. 노트마다 그 노트 옆에 `pic` 폴더를 따로 두고 싶으시면 **"In subfolder under current folder"**를 고르고 이름을 `pic`으로 하세요.

## 편집창에 순수 Markdown 만 보이게 하려면

편집 창에 꾸밈 없는 순수 마크다운만 보이게 하려면 **Settings → Editor → Default editing mode**를 **Source mode**로 바꾸시면 됩니다 (기본값인 Live Preview는 편집하면서 일부를 렌더링합니다).
